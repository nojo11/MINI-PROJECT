# Anti-MoMo Fraud Detection Frontend

Frontend implementation for the Anti-MoMo Fraud Detection web application using:

- React 19 + TypeScript + Vite
- pnpm
- Tailwind CSS 4
- shadcn/ui-style component architecture
- React Router v7
- TanStack Query + Zustand
- React Hook Form + Zod
- Framer Motion
- Recharts

## Development

```bash
pnpm install
pnpm dev
```

## Quality checks

```bash
pnpm lint
pnpm test
pnpm build
```
